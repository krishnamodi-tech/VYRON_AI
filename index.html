    🛠️ VYRON AI 2.0 — Architecture & Configuration

    VYRON AI is architected for transparent, verifiable performance in competitive hackathon environments:

    🟢 Open-Weight AI Mode (Recommended)

    Powered by open-weight models (Llama 3.3 70B Versatile / Llama 3.1 8B / Qwen) via Groq or local OpenAI-compatible inference. Provides clause-by-clause reasoning and grounded document Q&A.

    🔵 Google Gemini Mode

    Powered by Google Gemini 1.5 Flash via official API. Can be configured alongside or in place of Groq.

    🟡 Client Hybrid Mode

    Runs directly via chunked direct translation, client-side Tesseract.js OCR, and Web Speech API. Completely functional even without cloud API keys!

    How to configure API Keys:

    1. Create or edit .env in the project root:
      2. # Open-Weight AI Model (Groq)
GROQ_API_KEY=your_groq_api_key_here
GROQ_MODEL=llama-3.3-70b-versatile

# (Optional) Google Gemini Alternative
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-1.5-flash
    2. Restart the backend server: python main.py
